# Docs

This directory contains public-facing operational documentation for Fixer MCP.

- `docker-smoke.md`: deterministic Docker smoke and heavier bootstrap E2E checks.
- `public-repo-export.md`: contract for the generated public repository export.
- `public-repo-installation.md`: managed installer, overrides, and update behavior.
- `../AGENTS_INSTALLATION.md`: end-to-end receiving-agent checklist.

The private workspace may contain additional planning or migration notes. Those are intentionally not exported here.
